# Agricultural Model

> Status: skeleton — expanded in Phase 1.

## Purpose

Document the agricultural knowledge base: zones, seasons, soils, crops — including
the source and quality of every important assumption.

## Planned contents

- Zone definitions with rainfall bands and irrigation access + provenance table
- Soil taxonomy simplification rationale
- Season windows for Maharashtra
- Crop parameter dictionary: meaning of every field, range semantics,
  tolerance scales (0–100), disease-risk model
- Provenance policy: `quality: assumed | curated | sample`, per-dataset meta blocks,
  upgrade path from assumption → cited source
- Known gaps requiring ICAR/university validation

## Current state (Phase 0)

Six validated datasets under `data/` with explicit disclaimers; all crop economics
flagged `assumed`.
