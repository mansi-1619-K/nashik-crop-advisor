# Evaluation

> Status: skeleton — harness built in Phase 6.

## Purpose

Define what is measured, how, and the rule that only measured numbers are reported.

## Planned contents

- Scenario benchmark format: zone/season/soil/water/weather + expected behaviour
  (expert-defined, synthetic, edge-case splits)
- Metrics: constraint-violation rate, top-K agreement, recommendation stability
  under perturbation, structured-output validity, fallback success rate, API latency
- Reproducible scripts under `evaluation/scripts`, fixtures under
  `evaluation/scenarios` and `evaluation/benchmarks`
- Reporting template that forbids unmeasured claims

## Current state (Phase 0)

Not started.
