# Weather Engine

> Status: skeleton — implemented in Phase 2.

## Purpose

Document the Open-Meteo integration and the translation of raw weather into
agricultural advisory signals.

## Planned contents

- Taluka → coordinates mapping and precision caveats
- Fetch strategy, caching, timeouts, fallbacks
- WMO weather-code parsing table
- Advisory signal catalogue (irrigation opportunity, heat stress, fungal-risk
  windows, spraying suitability) with severity/confidence semantics
- Explicit "heuristic advisory, not diagnosis" language policy

## Current state (Phase 0)

Not started.
