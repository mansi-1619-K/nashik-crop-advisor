# Limitations

> Status: living document — expanded every phase.

## Known limitations at Phase 0

1. **Assumed agronomy.** Every zone characteristic, crop range and economic figure
   is an unvalidated initial estimate. No recommendation should be acted upon.
2. **Simplified soil taxonomy** (6 classes, 5 compatibility levels) — real fields
   require soil testing.
3. **No engines yet.** Constraints, scoring, weather intelligence, economics,
   Gemini and RAG arrive in later phases.
4. **Sample market data.** `data/markets/sample-quotes.json` is illustrative only.
5. **Approximate taluka coordinates**, unsuitable for field-level precision.
6. **English-only UI**; Marathi labels exist in data but no localization yet.

## Standing honesty rules

- Never present estimates as measurements or sample data as live.
- Heuristic signals are advisories, never diagnoses.
- The tool supports decisions; it does not guarantee outcomes.
